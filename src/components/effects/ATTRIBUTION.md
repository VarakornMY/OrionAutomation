# Supplied animation components

GlowCursor, AnimatedContent, and Silk are adapted from the React Bits source supplied by the user. TypingAnimation and Text3DFlip are adapted from the supplied Magic UI source; Text3DFlip credits Aayush Bharti.

Adaptations: JavaScript conversion, existing framer-motion imports, local CSS in place of Tailwind utilities, semantic text accessibility, visible server-rendered content, motion controls, viewport-sized canvases, and conservative rendering resolution. The original shader implementations are retained.
